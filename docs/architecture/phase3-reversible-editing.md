# Phase 3：青岛 v3 完整旁路编辑器

## 状态与边界

Phase 3 的编辑器功能已经在 v3 sidecar 中形成完整闭环。它不修改 Legacy v2.5.4、正式 GitHub Pages、高德现网配置、Service Worker 或 v1.0.15 回退链，也不代表已经满足 Phase 6 正式切换门禁。

本阶段只服务青岛。所有搜索、坐标校验、模块、住宿区域和示例数据均限制在青岛及青岛旅行直接相关范围内。

## 已交付能力

### 地点与日程

- 运行时高德 JS `PlaceSearch` adapter；SDK 未注入时明确降级搜索 49 个 v2.5.4 青岛点位；
- 高德 GCJ-02 搜索坐标转换为带坐标系标识的 WGS84，搜索结果加入后保持 `review-required`；
- 自定义地点名称、别名、地址、坐标、类型、Logo、颜色、日期、到达时间、停留、费用、开放备注、预约、提醒、来源、锁定和 Plan B；
- 不参与规划的自定义地点可以只保存为候选，不会静默加入日程；
- 四个由现有青岛点位组合的可编辑日程模块；
- 同日／跨日移动，以及上移、下移、前一天、后一天等拖拽等价操作；
- 批量选择、跨日移动、优先级、锁定／解锁、停用、删除和恢复。

### 地图样式

- Logo 与地图编号使用两个独立模型，数字不会画入图标资源；
- 编号支持全程连续、每日重置、`D1-1`、隐藏和逐项自定义；
- Logo 支持独立图案与颜色，使用代码原生 SVG 占位图形，不使用 emoji；
- RouteStyle 支持颜色、粗细、透明度、实线／虚线／点线、箭头显示、方向、大小、间距、层级、可见性和整日／相邻路段范围；
- 修改 RouteStyle 只改变 RenderModel，不修改距离、时间、折线、Provider 或估算标志。

### 版本、存储与恢复

- 每次编辑都生成显式正向／逆向 Command 与审计说明；
- Undo／Redo 最多保留 50 个版本化语义快照，并与计划一起原子写入 IndexedDB；
- 页面重载后恢复当前计划和可执行 Undo／Redo 历史；
- 多计划新建、复制、重命名、归档、软删除、恢复、不可变快照和快照恢复；
- JSON 导入先校验再原子替换，兼容 Phase 2 导出 checksum；损坏导入不改变现有数据；
- 打印样式、Web Share 与剪贴板降级分享。

### 分析

- 住宿区域初筛比较老城、中心东部和东海岸三个区域；
- 结果只显示带优先级权重的 WGS84 直线距离，并标记 `estimated=true`、低置信度和数据边界；
- 缺少经过核验的路线时间、酒店价格、评分、库存和退改数据时，不输出正式酒店推荐。

## 增量重算数据流

```text
用户操作
  → 显式 EditCommand
  → Schema 与锁定边界校验
  → 识别受影响日期
  → 只重建相关时间轴、午休、相邻路线和冲突引用
  → 独立更新编号／Logo／RouteStyle RenderModel
  → 记录可执行历史
  → 原子自动保存计划与历史
```

Planner 不读取 DOM、地图实例、IndexedDB 或平台 SDK。Web 负责把表单、按钮和拖放转换为 Command；Provider 通过独立 port 注入。

## 不变量

- 锁定地点不能被移动、删除或停用；
- 无关日期在增量操作后严格不变；
- 每日路线段数量等于该日地点数减一（最小为零）；
- 删除与恢复、Undo 与 Redo 语义可逆；
- 页面重载后历史仍通过运行时 Schema；
- Logo 变化不改变编号，编号变化不改变 Logo；
- RouteStyle 变化不改变路线计算数据；
- 高德 SDK 缺失或失败时不伪造在线结果；
- 直线降级不能显示为道路距离或真实交通时间；
- 损坏导入不会覆盖当前计划。

## 仍属于后续迁移门禁

以下能力继续由 v3“完整攻略”工作区中的冻结版 v2.5.4 提供，不能因 Planner 完成而删除：高德地图、MarkerCluster、周边搜索、天气、实时路况、真实步行／公交／驾车路线、完整 8 日攻略、旅行工具、离线与 Service Worker。Planner 已原生接入真实 Leaflet 多底图、定位、点位联动和高德坐标链接，但真实路线 Provider 网关、完整内容批次仍属于后续架构与数据阶段；小程序属于 Phase 5。

## 回滚

v3 未被根 `index.html`、Pages 或 Service Worker 引用。回滚 Phase 3 只需回退本阶段的 sidecar 代码、Schema、测试和文档提交；v2.5.4 与 v1.0.15 无需重新构建或发布。
