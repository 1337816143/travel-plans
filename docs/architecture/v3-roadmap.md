## 下一批 Phase 3 切片

1. 将可执行 Undo／Redo 栈纳入版本化存储迁移，使页面重载后仍能安全恢复。
2. 接入高德搜索 Provider 的安全边界与“加入候选／某天／优先级”操作，不扩大公开密钥范围。
3. 完成自定义地点、MarkerStyle 与 RouteStyle 编辑，并保持 Logo 与编号分离。
4. 增加多计划、快照、归档、比较和批量编辑 UI。
5. 在真实路线 Provider 网关 ADR 通过后，以 Provider 结果替换直线降级段。

每个切片独立提交；架构、内容数据、UI 和图标资源不混在同一提交。
