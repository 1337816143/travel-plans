## Phase 1 后续切片

1. 扩展现有 49 个运行时点位的只读迁移器和计数对账，不手工复制动态事实。
2. 完成 TripPlan／TripDay／TripItem／RouteSegment 的不变量和版本迁移测试。
3. 定义 RouteProvider、WeatherProvider、SearchProvider 与 Storage ports；用固定 snapshot 做契约测试。
4. 实现确定性 Planner 的最小启发式，不接 UI、不请求实时网络。
5. 建立 Web PoC 的非正式入口，完成最小闭环后再讨论 UI 框架。

每个切片独立提交；架构、内容数据、UI 和图标资源不混在同一提交。
