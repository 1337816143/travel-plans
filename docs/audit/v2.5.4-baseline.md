## 版本身份问题与修复

根 README 仍称“当前版本 v1.0.0”，且把当前产品描述为早期单文件页面，与运行时 v2.5.4、canonical `src-v2/`、lazy bundle、Service Worker 和稳定回退事实脱节。本 PR 将 README 修正为 v2.5.4，并明确 v3 旁路、正式入口和动态信息边界。

`src-v2/core/app-state.js` 内部仍有 `APP_VERSION='2.0.0'`，部分旅行工具会把它显示或写入导出元数据。这是 Legacy 内部身份债务；Phase 0 不修改正式业务行为，只登记为风险，后续应以单独 v2 修复 PR 处理并重新跑全量 E2E。

## Legacy 回退

3. 加载器继续固定回退到 `versions/2026-07-27-v1.0.15.html`。

## Phase 0 结论

v2.5.4 可以继续作为不可变迁移基线。现有测试没有发现新的产品回归；发现的是可审计的架构与流程债务，详见 `v3-gap-analysis.md`。在 v3 达到功能一致性、迁移、数据和多设备门禁以前，v2.5.4 必须继续承载全部正式功能。
