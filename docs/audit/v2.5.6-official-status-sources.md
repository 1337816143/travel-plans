# v2.5.6 official status source policy

The release distinguishes two states that must never be conflated:

1. **Published operating status / service window** — official opening season, published daily service hours, museum closure weekday, or a scenic-area reopening notice.
2. **Same-day live safety status** — beach flag, emergency/weather warning, temporary closure, crowd-control instruction, broadcast, or on-site staff instruction.

The first can be stored as a verified snapshot. The second must be rechecked on the day and overrides the stored snapshot.

Primary sources used for the 2026-08-09 snapshot are stored alongside each item in `data/qingdao/ops/current-status-2026-08-09.json`.
