# v2.5.4 功能保留矩阵

状态定义：

- **完整保留**：本 PR 不改该功能，正式 Pages 继续由 v2.5.4 提供。
- **重构后替代**：未来必须由共享 v3 核心或平台适配器达到同一结果后，才能替换 Legacy。
- **暂由 Legacy 提供**：v3 尚未迁移；这不是删除许可。
- **尚未迁移**：本 PR 只建立模型或目录边界，没有可交付 UI。

所有条目在本 PR 中均保持“完整保留＋暂由 Legacy 提供”。“v3 目标”只是迁移责任，不表示已经实现。

## 切换原则

在以下证据全部成立前，任何一项都不得从 Legacy 删除：原版 8 日计划可完整恢复；内容字段和来源无损；地图、天气、路线、离线和本地状态回归通过；Web 与小程序结果一致；导入导出和 Schema 迁移可逆；桌面、手机与真机门禁通过；v2.5.4 和 v1.0.15 回退仍可访问。
