# v2.5.6 implementation scope

This release is mobile-first and additive over v2.5.5 while preserving `archive/v2.5.4-stable` as the immutable rollback anchor.

- Bottom mobile route drawer: horizontal swipe switches trip dates and refits the selected day.
- Map focus: point/context fitting accounts for the actual expanded drawer height.
- Fixed itinerary route layer: AMap Web Route Planning supplies actual walking, transit, or driving geometry, distance, and duration. Straight-line distance is not shown as an actual trip metric.
- Actual traffic detail is globally hidden by default.
- Double-click/double-tap itinerary text focuses the mapped place and shows previous/current/next route context.
- Map assistant: selected-day hourly forecast includes precipitation probability.
- Every fixed itinerary day has a nearby rain alternative in a horizontal pager.
- Added user candidates: 笨蛤蜊地标小吃大排档 (must-eat, exact store unverified), 沙子口休闲广场, Vya无涯coffee (exact store unverified), 青岛云上海天.
- Official operation snapshot covers all nine bathing beaches and major scenic/indoor venues; published service hours are explicitly separated from same-day live flags/temporary closures.
- v3 embeds the current root guide and is synchronized to v2.5.6 while its custom sidecar refuses to display straight-line distance/time as actual routing.
