# 青岛旅行微信小程序 v1.0.7

仓库采用文本分片保存小程序 ZIP，避免 GitHub 连接器对二进制文件的限制。

## 还原工程

在本目录运行：

```bash
python rebuild_package.py
```

会生成 `source-v1.0.7.zip`。解压后，在微信开发者工具中导入 `wechat-mini-program/` 目录。

发布前必须：

1. 将 `project.config.json` 中的 `touristappid` 替换为自己的小程序 AppID。
2. 在微信公众平台完善服务类目、隐私保护指引和用户协议。
3. 预约按钮当前复制官方链接或搜索关键词；直接跳转第三方小程序需要目标 AppID、页面路径及对方授权。
4. 预约状态目前保存在本机微信 Storage；跨设备同步需要接入微信云开发数据库。

已实现：腾讯原生地图、点位、逐日路线、预设目的地、搜索、其他推荐、必约清单，以及“未处理 / 已预约 / 已核验 / 放弃”全局联动。
