# Qingdao Travel Plans

2026年8月9日至16日青岛情侣旅行计划与交互地图。

- 线上入口：`index.html`
- 历史版本：`versions/`
- 当前版本：v1.0.0（2026-07-25）
- 技术：HTML/CSS/JavaScript、Leaflet 1.9.4、OpenStreetMap、MarkerCluster

## 重要说明

页面为单文件，可直接保存和打开；行程文字可离线阅读。Leaflet/MarkerCluster脚本和地图瓦片通过网络加载，因此完整地图功能需要联网。轮渡班次、潮汐、天气、浴场旗语、租衣商家营业状态和酒店目标日期成交价均需临行复核。

## 版本策略

每次更新根目录 `index.html`，同时在 `versions/` 中保留一个带日期与版本号的完整HTML快照，不删除历史版本。
